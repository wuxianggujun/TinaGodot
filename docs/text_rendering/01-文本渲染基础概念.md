## 1. 字体的本质

### 1.1 什么是字体？

字体本质上是**字形的集合**，每个字形定义了一个字符的视觉表现。

```
字体文件 = {
    字形1: 'A'的形状数据,
    字形2: 'B'的形状数据,
    字形3: 'a'的形状数据,
    ...
    元数据: 字距、行高等
}
```

### 1.2 矢量 vs 位图

#### 矢量字体（现代主流）
```
优点：
✅ 可无限缩放
✅ 文件小
✅ 质量高

格式：
- TrueType (.ttf)
- OpenType (.otf)
- WOFF/WOFF2 (Web字体)

存储方式：
贝塞尔曲线控制点
```

#### 位图字体（传统/特殊用途）
```
优点：
✅ 渲染快
✅ 可预设计像素级细节

缺点：
❌ 不可缩放
❌ 文件大

格式：
- BDF
- PCF
- BMFont
```

## 2. 字符 vs 字形

### 2.1 核心区别

```cpp
// 字符（Character）- Unicode码点
char32_t character = 'A';  // U+0041

// 字形（Glyph）- 视觉表现
// 同一个字符可能有多个字形：
// A → 字形1（普通）
// A → 字形2（粗体）
// A → 字形3（斜体）
```

### 2.2 一对多关系

#### 一个字符 → 多个字形
```
字符 'f' 可能渲染为：
- 独立字形: f
- 连字字形: ﬁ (fi连字)
- 连字字形: ﬀ (ff连字)
```

#### 多个字符 → 一个字形
```
阿拉伯语：
字符序列: م + ر + ح + ب + ا
渲染为: مرحبا (一个连写字形)
```

### 2.3 Godot中的表示

```cpp
// servers/text/text_server.h
struct Glyph {
    int32_t start;      // 源字符串起始位置
    int32_t end;        // 源字符串结束位置
    uint8_t count;      // 包含的字符数
    uint8_t repeat;     // 重复次数
    uint16_t flags;     // 标志位
    float x_off;        // X偏移
    float y_off;        // Y偏移
    float advance;      // 前进宽度
    RID font_rid;       // 字体资源ID
    int font_size;      // 字号
    int32_t index;      // 字形索引
};
```

## 3. 光栅化（Rasterization）

### 3.1 什么是光栅化？

将矢量字形转换为像素位图的过程。

```
矢量数据（贝塞尔曲线）
        ↓
    光栅化引擎
        ↓
    像素位图
```

### 3.2 光栅化流程

```cpp
// 伪代码
Bitmap rasterize_glyph(VectorGlyph glyph, int size) {
    // 1. 缩放字形到目标大小
    glyph.scale(size);
    
    // 2. 创建位图缓冲区
    Bitmap bitmap(width, height);
    
    // 3. 扫描转换
    for (int y = 0; y < height; y++) {
        for (int x = 0; x < width; x++) {
            // 判断像素是否在字形内部
            float coverage = calculate_coverage(x, y, glyph);
            bitmap.set_pixel(x, y, coverage);
        }
    }
    
    return bitmap;
}
```

### 3.3 FreeType的作用

Godot使用**FreeType**库进行光栅化：

```cpp
// modules/text_server_adv/text_server_adv.cpp
FT_Load_Glyph(face, glyph_index, FT_LOAD_DEFAULT);
FT_Render_Glyph(face->glyph, FT_RENDER_MODE_NORMAL);

// 获取渲染后的位图
FT_Bitmap &bitmap = face->glyph->bitmap;
```

## 4. 抗锯齿技术

### 4.1 为什么需要抗锯齿？

```
无抗锯齿（锯齿明显）：
█░░░░
█░░░░
█░░░░
░█░░░
░░█░░

有抗锯齿（边缘平滑）：
█▓░░░
█▓░░░
█▓░░░
▓█▓░░
░▓█▓░
```

### 4.2 灰度抗锯齿（Grayscale Anti-aliasing）

**原理**：使用灰度值表示像素覆盖率

```cpp
// 每个像素存储0-255的灰度值
pixel_value = coverage * 255;

// 示例
0%覆盖   → 0   (白色)
25%覆盖  → 64  (浅灰)
50%覆盖  → 128 (中灰)
75%覆盖  → 192 (深灰)
100%覆盖 → 255 (黑色)
```

**Godot实现**：
```cpp
// TextServer::FontAntialiasing
FONT_ANTIALIASING_GRAY  // 标准灰度抗锯齿
```

### 4.3 LCD亚像素抗锯齿（LCD Subpixel Anti-aliasing）

**原理**：利用LCD屏幕的RGB子像素排列

```
普通像素：
[  像素  ]

LCD子像素：
[R][G][B]  ← 可以独立控制！
```

**水平分辨率提升3倍**：

```
灰度抗锯齿（1个像素）：
[灰色]

LCD抗锯齿（3个子像素）：
[R:暗][G:中][B:亮]
```

**Godot实现**：
```cpp
// TextServer::FontAntialiasing
FONT_ANTIALIASING_LCD  // LCD亚像素抗锯齿

// TextServer::FontLCDSubpixelLayout
FONT_LCD_SUBPIXEL_LAYOUT_HRGB  // 水平RGB
FONT_LCD_SUBPIXEL_LAYOUT_HBGR  // 水平BGR
FONT_LCD_SUBPIXEL_LAYOUT_VRGB  // 垂直RGB
FONT_LCD_SUBPIXEL_LAYOUT_VBGR  // 垂直BGR
```

### 4.4 抗锯齿对比

| 技术 | 分辨率 | 适用场景 | 缺点 |
|------|--------|---------|------|
| 无抗锯齿 | 1x | 像素艺术 | 锯齿明显 |
| 灰度抗锯齿 | 1x | 通用 | 边缘略模糊 |
| LCD抗锯齿 | 3x水平 | 静态文本 | 彩色边缘 |

## 5. 字体度量（Font Metrics）

### 5.1 关键概念

```
        ┌─────────────────┐ ← Ascent（上升高度）
        │                 │
        │      Text       │
────────┼─────────────────┼──── Baseline（基线）
        │                 │
        └─────────────────┘ ← Descent（下降高度）
        
        ├─────────────────┤
              Advance（前进宽度）
```

### 5.2 Godot中的度量

```cpp
// scene/resources/font.h
class Font {
    virtual real_t get_height(int p_font_size) const;
    virtual real_t get_ascent(int p_font_size) const;

    virtual real_t get_underline_position(int p_font_size) const;
    virtual real_t get_underline_thickness(int p_font_size) const;
};
```

### 5.3 字距调整（Kerning）

**问题**：某些字符组合间距不均

```
无字距调整：
A V  ← 间距太大

有字距调整：
AV   ← 间距合适
```

**Godot实现**：
```cpp

    int64_t p_size,
```

## 6. 字形缓存

### 6.1 为什么需要缓存？

光栅化是**昂贵的操作**：

```
渲染 "Hello" 5次：
无缓存：光栅化 H, e, l, l, o × 5 = 25次
有缓存：光栅化 H, e, l, o × 1 = 4次（l复用）
```

### 6.2 缓存策略

```cpp
// 缓存键 = (字体, 字号, 字形索引, 亚像素偏移)
struct CacheKey {
    RID font;
    int size;
    int glyph_index;
    int subpixel_offset;  // 0-3（1/4像素精度）
};

// 缓存值 = 渲染后的位图
struct CachedGlyph {
    Rect2 rect;        // 在纹理图集中的位置
    Rect2 uv_rect;     // UV坐标
    int texture_idx;   // 纹理索引
};
```

## 8. 关键要点总结

1. **字体 = 字形集合**，存储为矢量数据
2. **字符 ≠ 字形**，一对多或多对一关系
3. **光栅化**将矢量转换为像素，FreeType负责此工作
4. **抗锯齿**平滑边缘，LCD技术可提升3倍水平分辨率
5. **字形缓存**避免重复光栅化，提升性能
