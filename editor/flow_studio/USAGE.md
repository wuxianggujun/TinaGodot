# FlowStudio 可视化编辑器使用指南

## 启动编辑器

编译并运行 Godot 编辑器后，你会在底部面板看到一个 **"FlowGraph"** 标签。点击它即可打开 FlowStudio 可视化编辑器。

## 基本操作

### 1. 创建节点

有两种方式创建节点：

**方式 A：从节点库拖动**
1. 在左侧节点库中找到你需要的节点
2. 双击节点名称，节点会出现在画布中央

**方式 B：右键菜单（即将实现）**
1. 在画布空白处右键
2. 从弹出菜单选择节点类型

### 2. 移动节点

- 点击并拖动节点的标题栏即可移动节点
- 使用鼠标滚轮缩放画布
- 按住鼠标中键拖动可以平移画布

### 3. 连接节点

1. 点击源节点的**输出端口**（右侧的圆点）
2. 拖动到目标节点的**输入端口**（左侧的圆点）
3. 松开鼠标完成连接

**端口颜色说明：**
- ⚪ 白色 - 执行流（控制流）
- 🔵 蓝色 - 整数 (Int)
- 🟢 绿色 - 浮点数 (Float)
- 🟡 黄色 - 字符串 (String)
- 🔴 红色 - 布尔值 (Bool)
- 🟣 紫色 - 二维向量 (Vector2)
- 🟠 橙色 - 颜色 (Color)
- ⚫ 灰色 - 任意类型 (Any)

### 4. 删除节点

1. 选中要删除的节点
2. 按 `Delete` 键或 `Backspace` 键

### 5. 断开连接

- 右键点击连接线，选择"断开连接"
- 或者在连接的输出端口上右键，选择断开

## 节点类型

### Event 节点（事件）

#### Start
- **描述**：程序的入口点
- **输出端口**：
  - `execute` (执行流) - 程序开始执行

### I/O 节点（输入输出）

#### Print
- **描述**：打印消息到控制台
- **输入端口**：
  - `execute` (执行流) - 触发打印
  - `message` (任意类型) - 要打印的内容
- **输出端口**：
  - `execute` (执行流) - 打印完成后继续

### Data 节点（数据）

#### Constant
- **描述**：提供一个常量值
- **输出端口**：
  - `value` (根据类型) - 常量值
- **属性**：
  - `value` - 常量的值
  - `type` - 数据类型

#### Variable
- **描述**：读取或写入变量
- **输入端口**：
  - `execute` (执行流) - 触发写入（Set 模式）
  - `value` (任意类型) - 要写入的值（Set 模式）
- **输出端口**：
  - `execute` (执行流) - 写入完成（Set 模式）
  - `value` (任意类型) - 变量的值（Get 模式）
- **属性**：
  - `name` - 变量名
  - `mode` - "Get" 或 "Set"

### Math 节点（数学运算）

#### Add
- **描述**：加法运算
- **输入端口**：
  - `A` (数值) - 第一个加数
  - `B` (数值) - 第二个加数
- **输出端口**：
  - `Result` (数值) - 计算结果

### Control Flow 节点（控制流）

#### If/Else
- **描述**：条件分支
- **输入端口**：
  - `execute` (执行流) - 触发判断
  - `condition` (布尔值) - 条件
- **输出端口**：
  - `true` (执行流) - 条件为真时执行
  - `false` (执行流) - 条件为假时执行

## 示例：创建 Hello World 程序

1. **创建 Start 节点**
   - 在节点库中双击 "Event > Start"
   - 节点出现在画布中央

2. **创建 Print 节点**
   - 在节点库中双击 "I/O > Print"
   - 将 Print 节点拖到 Start 节点右侧

3. **连接节点**
   - 从 Start 节点的 `execute` 输出端口拖线到 Print 节点的 `execute` 输入端口
   - 连接成功后会显示白色连线

4. **设置消息（即将实现）**
   - 选中 Print 节点
   - 在属性面板中设置 `message` 为 "Hello, World!"

5. **运行程序**
   - 点击工具栏的 [Run] 按钮
   - 查看控制台输出

## 示例：创建加法计算器

1. **创建节点**
   - Start 节点
   - 两个 Constant 节点（值分别为 10 和 20）
   - 一个 Add 节点
   - 一个 Print 节点

2. **连接执行流**
   - Start.execute → Print.execute

3. **连接数据流**
   - Constant(10).value → Add.A
   - Constant(20).value → Add.B
   - Add.Result → Print.message

4. **运行**
   - 点击 [Run]
   - 控制台输出：30

## 工具栏按钮

- **New** - 创建新的流程图
- **Open** - 打开已保存的流程图文件 (.tflow)
- **Save** - 保存当前流程图
- **Run** - 运行流程图（需要先实现解释器）
- **Stop** - 停止执行

## 快捷键

- `Delete` / `Backspace` - 删除选中的节点
- `Ctrl+Z` - 撤销（即将实现）
- `Ctrl+Y` - 重做（即将实现）
- `Ctrl+C` - 复制（即将实现）
- `Ctrl+V` - 粘贴（即将实现）
- `Ctrl+S` - 保存
- `F5` - 运行

## 文件格式

FlowStudio 使用 `.tflow` 文件格式保存流程图，这是一个 JSON 格式的文本文件。

示例文件结构：
```json
{
  "version": "1.0",
  "nodes": [
    {
      "id": 1,
      "type": "event.start",
      "position": [100, 100],
      "properties": {},
      "input_ports": [],
      "output_ports": [
        {
          "name": "execute",
          "type": 0,
          "direction": 1
        }
      ]
    }
  ],
  "connections": [
    {
      "from_node": 1,
      "from_port": "execute",
      "to_node": 2,
      "to_port": "execute"
    }
  ],
  "variables": {}
}
```

## 故障排除

### 节点无法连接

- 检查端口类型是否兼容
- 执行流（白色）只能连接到执行流
- 数据端口需要类型兼容（如 Int 可以连到 Float）

### 编辑器没有显示

- 确保编译成功
- 检查底部面板是否有 "FlowGraph" 标签
- 查看控制台是否有错误信息

### 节点显示不正常

- 尝试关闭并重新打开编辑器
- 检查节点定义是否正确

## 技术细节

- **图编辑器**：基于 Godot 的 `GraphEdit` 控件
- **节点**：使用 `GraphNode` 控件
- **数据模型**：使用 `FlowGraph`, `FlowNode`, `FlowPort`, `FlowConnection` 类
- **渲染**：纯 C++ 实现，无需 GDScript
