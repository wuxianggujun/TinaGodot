Reduce binary size by limiting translations to Chinese only

Only include Chinese (zh_CN) translations instead of all 42+ languages:
- editor UI translations: 42 languages -> 1 language (zh_CN)
- property translations: 25 languages -> 1 language (zh_CN)  
- doc translations: 11 languages -> 1 language (zh_CN)
- extractable translations: kept as-is

This reduces ~98MB of translation data to ~15MB, significantly
reducing the editor binary size.

English is always available as the fallback language.
