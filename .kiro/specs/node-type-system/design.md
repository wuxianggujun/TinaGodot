# TinaFlowStudio 节点类型系统设计文档

## 概述

本文档定义 TinaFlowStudio 可视化编程系统的节点类型体系。节点是可视化编程的基本单元，用户通过连接不同类型的节点来构建程序逻辑。

## 设计目标

1. **易于理解**：节点类型清晰，功能明确，适合初学者
2. **功能完整**：覆盖基本编程需求（变量、运算、控制流、I/O）
3. **可扩展**：支持未来添加新的节点类型
4. **类型安全**：节点连接时进行类型检查，减少错误
5. **视觉友好**：不同类型节点有明确的视觉区分

## 核心概念

### 节点（Node）
- 节点是可视化编程的基本单元
- 每个节点有输入端口（Input Ports）和输出端口（Output Ports）
- 节点通过端口连接形成数据流和控制流

### 端口（Port）
- **输入端口**：接收数据或控制信号
- **输出端口**：输出数据或控制信号
- 每个端口有明确的数据类型

### 连接（Connection）
- 连接将一个节点的输出端口连接到另一个节点的输入端口
- 只有类型兼容的端口才能连接

## 节点分类体系

### 1. 事件节点（Event Nodes）
**颜色标识**：🟢 绿色  
**用途**：程序的入口点，响应各种事件

#### 1.1 开始节点（Start）
- **描述**：程序的起始点
- **输入端口**：无
- **输出端口**：
  - `执行` (Execution) - 控制流输出
- **图标**：▶️ 播放图标

#### 1.2 按键事件（Key Event）
- **描述**：响应键盘按键
- **输入端口**：无
- **输出端口**：
  - `执行` (Execution) - 控制流输出
  - `按键` (Key) - String 类型，按下的键名
- **属性**：
  - 监听的按键（下拉选择：W/A/S/D/Space/Enter 等）
  - 事件类型（按下/释放/持续按住）

#### 1.3 定时器事件（Timer Event）
- **描述**：定时触发
- **输入端口**：无
- **输出端口**：
  - `执行` (Execution) - 控制流输出
  - `计数` (Count) - Integer 类型，触发次数
- **属性**：
  - 间隔时间（秒）
  - 是否循环

---

### 2. 数据节点（Data Nodes）
**颜色标识**：🔵 蓝色  
**用途**：存储和操作数据

#### 2.1 变量节点（Variable）
- **描述**：存储一个值
- **输入端口**：
  - `设置` (Set) - 控制流输入
  - `值` (Value) - Any 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出
  - `值` (Value) - Any 类型
- **属性**：
  - 变量名
  - 数据类型（Integer/Float/String/Boolean）
  - 初始值

#### 2.2 常量节点（Constant）
- **描述**：提供一个固定值
- **输入端口**：无
- **输出端口**：
  - `值` (Value) - 根据类型变化
- **属性**：
  - 数据类型
  - 常量值
- **变体**：
  - 整数常量
  - 浮点数常量
  - 字符串常量
  - 布尔常量

#### 2.3 类型转换（Type Cast）
- **描述**：转换数据类型
- **输入端口**：
  - `输入` (Input) - Any 类型
- **输出端口**：
  - `输出` (Output) - 目标类型
- **属性**：
  - 目标类型

---

### 3. 运算节点（Operation Nodes）
**颜色标识**：🟡 黄色  
**用途**：执行各种运算

#### 3.1 数学运算（Math Operation）
- **描述**：基本数学运算
- **输入端口**：
  - `A` - Number 类型
  - `B` - Number 类型
- **输出端口**：
  - `结果` (Result) - Number 类型
- **属性**：
  - 运算符（+、-、×、÷、%、^）
- **变体**：
  - 加法（Add）
  - 减法（Subtract）
  - 乘法（Multiply）
  - 除法（Divide）
  - 取模（Modulo）
  - 幂运算（Power）

#### 3.2 比较运算（Comparison）
- **描述**：比较两个值
- **输入端口**：
  - `A` - Any 类型
  - `B` - Any 类型
- **输出端口**：
  - `结果` (Result) - Boolean 类型
- **属性**：
  - 比较符（==、!=、>、<、>=、<=）

#### 3.3 逻辑运算（Logic Operation）
- **描述**：布尔逻辑运算
- **输入端口**：
  - `A` - Boolean 类型
  - `B` - Boolean 类型（NOT 运算只需要 A）
- **输出端口**：
  - `结果` (Result) - Boolean 类型
- **属性**：
  - 运算符（AND、OR、NOT、XOR）

#### 3.4 字符串操作（String Operation）
- **描述**：字符串处理
- **输入端口**：
  - `字符串` (String) - String 类型
  - `参数` (Parameter) - 根据操作变化
- **输出端口**：
  - `结果` (Result) - String 或其他类型
- **属性**：
  - 操作类型（拼接、分割、长度、子串、替换）

---

### 4. 控制流节点（Control Flow Nodes）
**颜色标识**：🟠 橙色  
**用途**：控制程序执行流程

#### 4.1 条件分支（If/Else）
- **描述**：根据条件选择执行路径
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `条件` (Condition) - Boolean 类型
- **输出端口**：
  - `真` (True) - 控制流输出
  - `假` (False) - 控制流输出
- **图标**：◆ 菱形

#### 4.2 循环（Loop）
- **描述**：重复执行一段代码
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `次数` (Count) - Integer 类型（可选）
- **输出端口**：
  - `循环体` (Body) - 控制流输出
  - `索引` (Index) - Integer 类型，当前循环次数
  - `完成` (Complete) - 控制流输出
- **属性**：
  - 循环类型（固定次数/条件循环/无限循环）

#### 4.3 等待（Wait）
- **描述**：暂停执行一段时间
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `时间` (Duration) - Float 类型（秒）
- **输出端口**：
  - `完成` (Complete) - 控制流输出

#### 4.4 序列（Sequence）
- **描述**：按顺序执行多个分支
- **输入端口**：
  - `执行` (Execution) - 控制流输入
- **输出端口**：
  - `然后 1` (Then 1) - 控制流输出
  - `然后 2` (Then 2) - 控制流输出
  - `然后 3` (Then 3) - 控制流输出
  - ...（可动态添加）

---

### 5. 输入输出节点（I/O Nodes）
**颜色标识**：🟣 紫色  
**用途**：与外部交互

#### 5.1 打印（Print）
- **描述**：输出信息到控制台
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `消息` (Message) - Any 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出
- **图标**：💬 对话框

#### 5.2 输入（Input）
- **描述**：获取用户输入
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `提示` (Prompt) - String 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出
  - `值` (Value) - String 类型

#### 5.3 显示文本（Show Text）
- **描述**：在屏幕上显示文本
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `文本` (Text) - String 类型
  - `位置` (Position) - Vector2 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出

---

### 6. 2D 图形节点（2D Graphics Nodes）
**颜色标识**：🔴 红色  
**用途**：2D 图形操作（利用 Godot 2D 能力）

#### 6.1 创建精灵（Create Sprite）
- **描述**：创建一个 2D 精灵
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `纹理` (Texture) - Texture 类型
  - `位置` (Position) - Vector2 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出
  - `精灵` (Sprite) - Sprite2D 对象引用

#### 6.2 移动对象（Move Object）
- **描述**：移动一个 2D 对象
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `对象` (Object) - Node2D 对象引用
  - `位置` (Position) - Vector2 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出

#### 6.3 绘制形状（Draw Shape）
- **描述**：绘制基本形状
- **输入端口**：
  - `执行` (Execution) - 控制流输入
  - `形状` (Shape) - 枚举（矩形/圆形/线条）
  - `位置` (Position) - Vector2 类型
  - `大小` (Size) - Vector2 或 Float
  - `颜色` (Color) - Color 类型
- **输出端口**：
  - `执行` (Execution) - 控制流输出

## 数据类型系统

### 基础类型
1. **Integer**（整数）：-2147483648 到 2147483647
2. **Float**（浮点数）：小数
3. **String**（字符串）：文本
4. **Boolean**（布尔）：true/false
5. **Vector2**（二维向量）：(x, y)
6. **Color**（颜色）：RGBA

### 特殊类型
1. **Execution**（执行流）：控制流连接，不携带数据
2. **Any**（任意类型）：可以接受任何类型
3. **Object**（对象引用）：引用场景中的节点

### 类型兼容规则
- Integer 可以自动转换为 Float
- 任何类型都可以转换为 String（用于打印）
- Boolean 可以转换为 Integer（true=1, false=0）
- 其他转换需要显式的类型转换节点

## 端口连接规则

### 控制流连接
- 白色连线
- 一个输出端口可以连接多个输入端口（广播）
- 一个输入端口只能连接一个输出端口

### 数据流连接
- 彩色连线（根据数据类型）
- 一个输出端口可以连接多个输入端口
- 一个输入端口只能连接一个输出端口
- 必须类型兼容才能连接

### 连接验证
- 连接时实时检查类型兼容性
- 不兼容的连接显示红色警告
- 悬空的必需输入端口显示黄色警告

## 核心决策

### ✅ 已确定的设计决策

1. **执行方式**：**解释执行优先**
   - MVP 和开发期使用解释执行
   - 支持热重载、调试、断点
   - 未来版本支持代码生成优化（发布期）
   - 详见：`execution-model.md` 第 9 节

2. **节点命名**：**中文为主，英文为辅**
   - UI 显示中文名称（易于初学者）
   - 内部 ID 使用英文（如 `io.print`）
   - 支持多语言切换（未来功能）

3. **默认值处理**：**四级优先级**
   - 连接的输出端口值 > 节点属性值 > 端口默认值 > 类型默认值
   - 详见：`type-system-advanced.md` 第 7 节

4. **错误处理**：**分级处理，不中断执行**
   - Warning：打印警告，继续执行
   - Error：跳过当前节点，继续执行
   - Fatal：停止整个图
   - 详见：`execution-model.md` 第 6 节

5. **类型系统**：**强类型 + 有限隐式转换**
   - 基础类型：Int/Float/String/Bool
   - 复合类型：Array/Dictionary
   - 特殊类型：Null/Option/Union（减少 Any 使用）
   - 详见：`type-system-advanced.md`

6. **调试功能**：**完整的调试支持**
   - 断点和单步执行
   - 执行路径高亮
   - 端口值监视
   - 详见：`execution-model.md` 第 11 节（未来扩展）

## 实现策略总结

### 核心架构：解释执行引擎

TinaFlowStudio 采用**解释执行**作为核心执行方式，提供最佳的开发体验和调试能力。

```
架构层次：
┌─────────────────────────────────────┐
│   UI 层（GraphEdit + 节点编辑器）    │
├─────────────────────────────────────┤
│   图管理层（加载/保存/验证）         │
├─────────────────────────────────────┤
│   解释执行引擎（核心）               │
│   - 事件队列                        │
│   - 执行上下文                      │
│   - 节点执行器                      │
│   - 端口值缓存                      │
├─────────────────────────────────────┤
│   调试层（断点/单步/监视）           │
├─────────────────────────────────────┤
│   Godot 引擎（主循环/渲染/输入）     │
└─────────────────────────────────────┘
```

### 开发路线图

#### 阶段 1：MVP（解释执行核心）
**目标**：实现可运行的最小系统

1. **解释执行引擎**
   - 事件队列和调度
   - 节点执行器框架
   - 执行流传播
   - 数据流求值

2. **基础节点**（6-8 个）
   - Start（事件）
   - Print（I/O）
   - 常量（Int/String）
   - 变量（读/写）
   - 加法（运算）
   - If/Else（控制流）

3. **图编辑器**
   - 基于 GraphEdit 的画布
   - 节点拖拽和连接
   - 基础验证（类型检查）

4. **调试支持**
   - 执行路径高亮
   - 端口值显示
   - 基础日志输出

**交付物**：可以运行"Hello World"程序的原型

#### 阶段 2：功能扩展
**目标**：完善节点库和调试功能

1. **更多节点**（20+ 个）
   - 循环、等待、序列
   - 比较、逻辑运算
   - 字符串操作
   - 数组/字典操作
   - 按键事件、定时器

2. **高级调试**
   - 断点和单步执行
   - 变量监视面板
   - 调用栈显示
   - 性能分析

3. **图管理**
   - 保存/加载（JSON 格式）
   - 撤销/重做
   - 复制/粘贴
   - 搜索和替换

**交付物**：功能完整的可视化编程环境

#### 阶段 3：优化和扩展
**目标**：性能优化和高级功能

1. **性能优化**
   - 端口值缓存
   - 死代码消除
   - 常量折叠
   - 执行路径优化

2. **高级功能**
   - 子图/函数节点
   - 自定义节点
   - 2D 图形节点
   - 资源管理

3. **代码生成（可选）**
   - GDScript 代码生成
   - 优化和内联
   - 发布打包

**交付物**：生产就绪的可视化编程系统

### 技术选型确认

| 组件 | 技术选择 | 理由 |
|------|---------|------|
| UI 框架 | Godot GraphEdit | 原生支持，性能好 |
| 执行引擎 | 解释执行（GDScript） | 开发体验优先 |
| 数据格式 | JSON | 易读、易调试、跨平台 |
| 类型系统 | 强类型 + 有限隐式转换 | 平衡安全性和易用性 |
| 调试支持 | 完整（断点/单步/监视） | 教学和开发必需 |
| 代码生成 | 未来可选 | 性能优化备选方案 |

### 成功标准

**MVP 验收标准**：
- [ ] 可以创建和连接节点
- [ ] 可以运行简单程序（Hello World）
- [ ] 可以看到执行过程（高亮）
- [ ] 可以查看端口值
- [ ] 可以保存和加载图
- [ ] 编译期类型检查正常
- [ ] 运行期错误不崩溃

**性能目标**：
- 支持 1000+ 节点的图
- 保持 60 FPS（单帧 < 16ms）
- 启动时间 < 1 秒
- 内存占用 < 100MB

**用户体验目标**：
- 5 分钟内学会基本操作
- 10 分钟内完成第一个程序
- 错误提示清晰易懂
- 操作流畅无卡顿
